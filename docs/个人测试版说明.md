# 个人测试版说明

- Android 测试包在本机 `build/映你-个人测试版.apk`；它包含首次建号凭证，请勿公开传播。首次打开时由本人设置手机号和密码，手机号不做短信验证。
- 使用 HTTPS 连接服务器的独立路径；服务器服务名为 `yingni.service`，模型密钥与初始化凭证保存在服务器数据目录下的受限 `.env`，不进入 Git。
- 服务器数据位于 `/mnt/docker-data/WR-KidBookAI/yingni/data`；应用代码和虚拟环境也在同一项目目录内。系统服务及 Nginx 反向代理使用系统配置目录，现有站点配置有备份。
- 开发用本机签名密钥生成的测试包不适合作为公开发布包。后续升级需要使用相同签名密钥；丢失密钥会影响覆盖安装。
- 本地重建需要 Android SDK 35、构建工具 35.0.0、JDK，以及未提交的 `.bootstrap` 初始化凭证：运行 `python android/build.py`。
- `server/test_app.py` 在隔离临时目录测试业务流程；`server/live_smoke.py` 调用真实模型并产生费用。测试不覆盖真实手机、图片质量评价、个别个人信息的可靠删除或独立备份。
- 诺诺没有头像时会在聊天后自行选择并创建；有头像后自行决定是否更换，成功更换至少相隔 7 天；判断与生成在后台进行，可能产生模型费用，不保证每次聊天都会更换。个人头像、聊天背景和整个 App 的主题在「我的」中设置；个人头像会在设备上缩小后上传，原图不设 2 MB 限制。
- 聊天输入框的加号支持上传 TXT、DOCX、PDF，文件先上传并等待用户输入文字、点击发送，原文件和提取文字保存在服务器；“我的文件”可再次引用、下载和删除。读取仅覆盖可提取的文字，扫描页、图片和 Word 页眉页脚不在识别范围。当前上限为单文件 10 MB、每次 3 个文件、总计 6 万字及 PDF 100 页。
- 文件发送给诺诺时，提取文字会传给聊天模型；清除聊天和记忆不会清除保存的文件，应在“我的文件”中单独删除。删除文件不会抹去历史聊天中已经生成的文字回复。
