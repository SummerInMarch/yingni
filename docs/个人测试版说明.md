# 个人测试版说明

- Android 测试包在本机 `build/映你-个人测试版.apk`；它包含首次建号凭证，请勿公开传播。首次打开时由本人设置手机号和密码，手机号不做短信验证。
- 使用 HTTPS 连接服务器的独立路径；服务器服务名为 `yingni.service`，模型密钥与初始化凭证保存在服务器数据目录下的受限 `.env`，不进入 Git。
- 服务器数据位于 `/mnt/docker-data/WR-KidBookAI/yingni/data`；应用代码和虚拟环境也在同一项目目录内。系统服务及 Nginx 反向代理使用系统配置目录，现有站点配置有备份。
- 开发用本机签名密钥生成的测试包不适合作为公开发布包。后续升级需要使用相同签名密钥；丢失密钥会影响覆盖安装。
- 本地重建需要 Android SDK 35、构建工具 35.0.0、JDK，以及未提交的 `.bootstrap` 初始化凭证：运行 `python android/build.py`。
- `server/test_app.py` 在隔离临时目录测试业务流程；`server/live_smoke.py` 调用真实模型并产生费用。测试不覆盖真实手机、图片质量评价、个别个人信息的可靠删除或独立备份。
- 诺诺没有头像时，进入聊天或聊天后会触发后台创建，由她自行选择头像；有头像后自行决定是否更换，每周随机时间决定一次；判断与生成在后台进行，可能产生模型费用，不保证每次聊天都会更换。个人头像、聊天背景和整个 App 的主题在「我的」中设置；个人头像会在设备上缩小后上传，原图不设 2 MB 限制。
- 聊天输入框的加号支持上传 TXT、MD、DOCX、PDF，文件先上传并等待用户输入文字、点击发送，原文件和提取文字保存在服务器；“我的文件”可再次引用、下载和删除。读取仅覆盖可提取的文字，扫描页、图片和 Word 页眉页脚不在识别范围。当前上限为单文件 10 MB、每次 3 个文件、PDF 100 页。
- 文件发送给诺诺时，提取文字会传给聊天模型；清除聊天和记忆不会清除保存的文件，应在“我的文件”中单独删除。删除文件不会抹去历史聊天中已经生成的文字回复。
- 聊天记录显示北京时间，并向聊天模型提供每条消息的时间；已有记录沿用此前保存的时间，新消息以服务器收到请求的时间为准。
- 诺诺个人资料可通过聊天顶部入口查看；头像的旧生成记录没有保存描述，不能据此推断她的选择理由。心情是模拟状态，聊天后结合内容更新，空闲时每六小时可随机变化。
- 每周随机时间的服务器定时任务负责头像自主判断，判断为更换且生成成功后才保存新头像及描述。
- 语音需要服务端安全配置 DASHSCOPE_API_KEY；业务空间专属 Key 如需专属域名，还需配置 DASHSCOPE_WORKSPACE_ID。音色复刻使用 CosyVoice 3.5 Flash；“我的”页面可上传 10–20 秒清晰录音创建音色。
- 语音输入通过阿里云转写；诺诺较短回复随机合成语音，实际音频超过 20 秒则使用文字。语音文件保存在账号数据目录，清除聊天和记忆会删除语音。安卓录音需要安装带麦克风权限的新测试包。

- 新文件在后台分段，调用聊天模型提炼摘要，再由服务器上的本地模型生成向量并保存。聊天追问时检索摘要并取回原文，全文总结会汇总各段摘要。索引失败可在“我的文件”中重试。
- 建立索引时文件原文分段会发给 DeepSeek 生成摘要，向量由服务器本地生成。首次处理超长文件可能需要较长时间并产生模型调用费用。旧版因超过 6 万字未读取的文件可以在“我的文件”中重新建立索引。

- 首次发送附件时，较短文件的完整正文随问题交给聊天模型；长文件按正文逐段针对问题分析，再汇总结果。摘要索引独立在后台建立，后续追问按需检索。
